# ppsspp

Debian-native emulator build entry generated from:

legacy manifest for `ppsspp` from the migration knowledge base

Active build metadata is stored in `manifest.converted.yml`. The original legacy
manifest is preserved under the `legacy:` key for reference and auditability.

The MVP build script stages artifacts under:

`/artifacts/emulators/ppsspp/`

Set `EMULATOR_REAL_BUILD=1` to attempt the generic source fetch/build path. Many
emulators still need package-specific porting before real builds will succeed.
