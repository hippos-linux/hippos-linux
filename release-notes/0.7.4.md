### Controllers

- Dolphin, Cemu and RPCS3 pick up your controller from EmulationStation again. Xbox controllers over Bluetooth showed as disconnected in Dolphin and did nothing in Cemu and RPCS3, and the D-pad could land on the wrong buttons in Dolphin.
- Handhelds: a new Handheld controller type setting (per game, per system or for everything) changes the controller your built-in controls look like while that game runs. Try Xbox 360 for older games that ignore the controls. It's also in the quick menu while a game runs, and it goes back to normal when the game ends.
- Hotkey combos work from any controller, not only player 1's, and the buttons in a combo no longer also move around the menus.

### Quick menu

- The quick menu opens faster in games, and its Keys tab loads all your keys at once.
- Help prompts show on every quick menu screen, including the key picker and text pages.

### Laptops

- With the lid shut and a TV or monitor plugged in, EmulationStation turns the laptop's own screen off, so games and apps can't open on a screen you can't see. It comes back when you open the lid. If EmulationStation was on the laptop screen when you shut the lid, it moves to the other screen.
- Closing the lid now suspends on the charger too, unless a TV or monitor is plugged in.
- Speakers that sounded quiet or tinny on some laptops (ASUS ROG G14 and others with Cirrus amps) get their proper sound back.
- Suspend no longer asks for a password when an app like Plex or Jellyfin is open.
- Touchpad two-finger scrolling works.
- Machines with only Intel or open-source NVIDIA graphics start properly with variable refresh rate on.

### Updates

- Updates are now signed: HippOS only installs updates that come from us.
- An update only counts as working once EmulationStation or your desktop actually starts. If it doesn't, the next boot goes back to the version you had.
- Emulator updates show when a newer build of the same version is out.
- Apt packages you installed yourself are put back more reliably after an update: HippOS waits for the network, retries if the package lists can't be downloaded, and only gives up on a package when it's really gone.
- RetroArch, its cores and its core info now come and update together as one emulator package.

### Fixes

- Windows can open the HippOS shared folder: log in as `hippos` with the password `linux`. If you changed your root password, set it again once in EmulationStation and use that instead.
- Switching from a desktop back to EmulationStation works when Waydroid is running.
- R36S and other RK3326 handhelds no longer freeze when the GPU works hard.
- RetroArch uses its simpler menu on RK3326 handhelds, which suits their small screens.
- Apple IIgs (GSplus) runs on the Raspberry Pi.
- Scraping systems that cover several platforms finds games again.
- Brightness can't be set all the way to zero from the quick menu or settings.
- Log bundles are saved on your device when they can't be uploaded, so you can still send them.
- Launching games is a little quicker on small handhelds.
