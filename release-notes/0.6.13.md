### In-game quick menu

- Press Hotkey+A in a game to open the quick menu: save and load states, controller as mouse, the on-screen keyboard, brightness, volume, power mode and CPU/GPU stats.
- The Keys tab edits a game's pad-to-keyboard keys while you play, picking keys (and key combinations) from an on-screen keyboard.
- It follows your controller's button layout and shows the same button icons as EmulationStation.

### Apps and media

- **Media centers**: choose Kodi, Jellyfin, Emby Theater or Plex HTPC (PC only) from the main menu. The one you pick is installed for you, opens from the main menu, and gets the on-screen keyboard and controller as mouse.
- **Linux Apps** replaces Web Apps: installed apps sit alongside web apps.
- The Content Downloader has an Apps tab with Kodi, Flatpak apps and Steam Link.
- Handhelds use InputPlumber for their built-in controls, with settings in the controller menu.

### Updates

- Apps you installed with apt are installed into the new system during an update, so they're there straight after the restart.
- Files you added to the system yourself are kept across updates. System files you changed are moved to `/userdata/system/backups` instead of hiding the new version.
- Each machine keeps its own SSH host keys across updates.
- In desktop mode, HippOS Update in the menu lists every update (HippOS, EmulationStation, emulators and fixes) and installs them with live progress. Notifications tell you when an update is available, with an Update button, and show its progress.

### Saves and network shares

- Saves on a network share are written back to the share when it allows it. Each share has a switch to keep them read-only.
- Save folder names follow the common layout, so saves from other setups on a share line up.
- A share that points back at this machine's own storage is never merged in.
- Pre-installed Windows 98 games from packs load their existing install instead of asking to be installed again.

### Fixes

- EmulationStation saves game metadata before shutting down, restarting, logging out or switching to the desktop.
- Restarting while the scraper runs no longer crashes EmulationStation.
- Logging out of the desktop goes to the login screen.
- Emulator options set in EmulationStation now apply on every launch, not only the first.
- GameCube and Wii games fill the screen again.
- The chosen screen and resolution are kept after a game.
- The help bar shows face buttons by position.
- Audio output menus name a disconnected device instead of showing its raw id.
- The storage manager never mounts EFI system partitions.
- Log bundles include EmulationStation's log.
