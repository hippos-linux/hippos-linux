---
version: "0.6.6"
summary: "Per-game TDP and power profiles, Steam Controller 2 support, apt games in Ports, and apt upgrades no longer breaking NVIDIA drivers."
---

### Handhelds and power

- New per-game TDP setting on AMD handhelds such as the ROG Ally and Legion Go. TDP is now a percentage of what your device supports, and existing TDP settings are converted automatically.
- New per-game power profile setting (quiet, balanced, performance and so on) on devices whose firmware offers them. Both options only appear where your hardware supports them.
- Your global power settings are restored as soon as you quit a game, without slowing the return to EmulationStation.
- The CPU power mode now follows whether you're on battery or plugged in. A low controller battery no longer makes HippOS think the whole system is on battery.
- Handheld RGB LED colour, brightness and on/off settings now actually change the LEDs, and are kept after a reboot.

### Controllers

- The Steam Controller 2 works over Bluetooth, with its trackpad as a mouse and rumble in games.
- Emulators now use the same controller-to-player assignment EmulationStation chose.
- Arcade encoders in keyboard mode, such as the Ultimarc I-PAC, Mini-PAC and X-Arcade, now work as gamepads. Before, HippOS hid them as keyboards without creating the gamepad, so they did nothing.

### Display

- New Variable Refresh Rate switch in System Settings, for displays that support it on AMD, Intel and NVIDIA graphics. Turn it off if your screen flickers. Changing it needs a reboot.
- New FPS limit for EmulationStation's menus, which can save battery on handhelds.
- New option to limit how deep EmulationStation scans inside ROM folders, for large collections with many subfolders.

### Apps and apt

- Games you install with apt now appear in Ports automatically, and disappear when you remove them.
- Packages you install with apt are reinstalled automatically after a HippOS update. This needs an internet connection, and runs in the background on the first boot after updating.
- `apt upgrade` can no longer replace the NVIDIA driver with a version that doesn't match HippOS's kernel module, which left games and the desktop without graphics acceleration. The NVIDIA driver packages were meant to be held back already, but the hold never took effect.
- After a HippOS update, leftover package data from before the update no longer hides the new version's packages.

### Emulators

- Each system now runs the default emulator EmulationStation shows. Before, most systems quietly used a different one, so a system showing openMSX or Amiberry actually ran blueMSX or PUAE. If a game behaves differently, you can choose another emulator in the system's options.
- MSX, MSX2, MSX2+, MSX turboR, ColecoVision and Spectravideo games launch. The openMSX emulator was missing from previous releases. Real MSX machines need their system ROMs in `bios/openmsx`.
- Amiga games in Amiberry no longer fail to start when a controller is connected.
- Apple II games launch. The launcher was looking for the wrong AppleWin program.
- Fixed Visual Pinball failing to start, and PS3 `.ink` shortcuts in RPCS3.
- Choosing DOSBox Staging, Pygame, Pyxel or Solarus as a system's emulator now works.
- N-Gage games launch through EKA2L1. Install the N-Gage firmware once from EKA2L1 in the desktop menu.
- Sega Model 3 games launch. Supermodel couldn't find its game list before. The Supermodel-ES and legacy builds can now be chosen per system too.
- Standalone Snes9x can now be chosen as the SNES emulator.
- Commodore 64, VIC-20, C128, Plus/4 and PET games start. VICE couldn't find its system ROMs before. Your controller now works as the joystick, in port 2 on the C64 and C128, and the Hide Borders option works.
- ScummVM games start. A wrong startup option stopped ScummVM before it got to the game.
- Macintosh games start in Basilisk II. Before, it opened its settings window instead. Put a Mac ROM file (`.rom`) in `bios/macintosh`.
- Amiga WHDLoad games and IPF disk images work in Amiberry.
- Sega Lindbergh games no longer fail to start because of missing 32-bit libraries.
- Fixed emulators that couldn't find their own data files, such as ScummVM's menu themes and DOSBox Staging's CRT shaders.
- Lutris games appear in their own Lutris system.
- Kodi starts from EmulationStation when it's installed, and rebooting or shutting down from Kodi works.

### EmulationStation

- Starting a game no longer pauses the menu while the BIOS check runs.
- Fixed audio glitches when a game starts and when switching to Kodi.
- Fixed the rating stars and theme opacity values being clamped wrongly, a crash that could follow controller or settings changes, and random filtering in the netplay lobby.
- Menus stay responsive while long option lists load.
- The battery indicator now works on handhelds whose battery isn't named in the usual way.
- Fixed the year filter, quick search, the random system pick, and moving multi-disc (m3u) games.
- Updated scraper platforms and arcade game names, and Pico-8 carts are recognised more reliably.

### Audio

- HDMI audio is detected more reliably when EmulationStation or the desktop starts.

### Diagnostics

- Uploaded logs now include audio output and HDMI display details.
- Creating a support file from EmulationStation now works, as do the three-finger touch gestures and closing a running emulator from EmulationStation.
