### New emulators

- **Mesen 2** for NES, SNES, Game Boy, GBA, Master System, Game Gear, PC Engine, WonderSwan and more.
- **Stella** for Atari 2600, **gopher64** for Nintendo 64, **86Box** for classic PCs and **SheepShaver** for classic Macintosh.
- **Lunaria** runs Android games and apps (`.apk`, `.xapk`, `.apks`, `.aab`) alongside Waydroid. The Android resources it needs download on first boot.
- **OpenCDi** for Philips CD-i.

### Native default emulators

- Every system's default emulator is now a native Linux one; Windows emulators stay available as alternatives.
- Xbox uses xbased by default, Cave CV1000 uses MAME, and Gaelco and Sega Hikaru use the Odin core.
- Xbox 360 (xenia-edge) opens fullscreen without a menu bar and no longer asks for a profile.

### Windows games

- Windows game handling has been rebuilt: DXVK, vkd3d-proton, d7vk and DXVK-NVAPI are included, and each launch sets them up for the game.
- `.wsquashfs` and `.wtgz` Windows games play. Prefixes made on other systems are updated automatically the first time they run.
- Many more Windows options in the game settings: FPS limit, NTSync, FSR, DirectDraw through Vulkan, NVAPI and Reflex, a virtual desktop and more.
- Custom Wine runners go in `system/wine-runners/<name>`, including the files of a GE-Proton release. Wine Mono is included for runners that don't bring their own.
- `autorun.cmd` supports `LANG`, `SAVEDIR` and `SAVEFILES`; saves listed there are kept in your saves folder.

### Firmware installs itself

- **Switch**: Ryujinx, Eden and Citron install the firmware from `bios/switch/firmware`, or from a firmware `.zip` in `bios/switch`.
- **PS3**: RPCS3 installs `PS3UPDAT.PUP` from your BIOS folder before the first game.

### Fixes

- Closing a game with the exit hotkey always ends it, even when the emulator ignores the request, and no longer shows an error afterwards.
- Cemu no longer shows its first-run wizard.
- RPCS3 finds games packed in a `.squashfs` with an extra folder inside.
- ares keeps its saves in your saves folder, so games on read-only network shares no longer ask for a save location, and it finds its firmware in your BIOS folder.
- NanoBoyAdvance uses your GBA BIOS and starts fullscreen.
- melonDS works with DS and DSi firmware on read-only shares.
- MAME skips its game information screen.
- Dolphin no longer stops at a warning for NKit disc images.
- DOSBox-X boots Windows 98 disk images and closes without asking.
- Mesen 2 starts fullscreen.
- Ports start when launched from the remote API, and the API no longer starts the previously played game when you launch straight after closing one.
- Optional GameCube and DSi BIOS files are no longer reported as missing.
- Network shares you chose to ignore stay ignored.

### EmulationStation

- New anti-aliasing (MSAA) setting, a fixed brightness slider, and the scraper remembers its media and date filters.
- The screensaver uses less power, and language names show in their own language.
- Keypad Enter works as Enter, and copying a save state to a free slot works when a game only has an auto-save.
- The IP address shown by themes updates when the network changes.
- Arcade game names are updated to MAME 0.289.
