### RK3326 handhelds (R36S) — experimental

- A new image for RK3326 handhelds such as the R36S. On first boot it reads the screen settings from your handheld's original card, so the panel works without picking a model.
- The screen runs at 60 Hz, charging status shows in the menu, and the CPU is capped at 1008 MHz to keep the handheld cool.
- Waydroid and Quiver are left out of this image.
- Known issue: some units freeze now and then. It looks linked to a low battery and is still being investigated; keep the handheld charged while testing.

### Three images, one release

- Every release now comes as three images: PC (amd64), Raspberry Pi and RK3326 handhelds.
- The download page is new: pick your device and get the matching image.

### Faster game starts

- Games start much sooner after you press A: on an R36S the wait went from about 8.5 seconds to 1.6, and closing a game returns to the menu faster too. PCs and the Raspberry Pi get the same changes.

### New

- **Riverhorse**, a new PlayStation emulator.
- The store searches Flathub and Debian packages, and they install and remove like any other store item.
- Emulator updates run in one go: one notification, a failed emulator no longer stops the rest, and emulators that are no longer offered are removed.
- Gamescope settings apply per game and per system, and ports and Linux games can use Gamescope.
- SSH and Samba are switched on and off in **SERVICES**. Samba no longer starts unless it is on.
- Jellyfin and other Flatpak apps started from the menu can use your controller.

### Changes

- One Supermodel build replaces Supermodel-es and Supermodel-legacy; your NVRAM and save states move over when you update.
- Xenia Canary runs all Xbox 360 games; games set to the plain Xenia build use it automatically.
- Older duplicate RetroArch cores are gone. Games set to a removed core launch with its replacement (for example bsnes-mercury to bsnes-jg, fbalpha to FBNeo, parallel_n64 to Mupen64Plus-Next).

### Fixes

- The Wi-Fi switch turns the radio on again, and the Wi-Fi password is no longer written to the logs.
- The storage scanner no longer reads files on network shares, which made boot slow with a big network library.
- The boot splash stays up until the menu is ready, instead of showing a blank screen in between.
- Citron reads its settings, and Citron and Eden close with their exit shortcut.
- Xenia Canary starts on a fresh system.
- Games with a lot of console output no longer stop early.
- After an OS update, programs you installed with apt are reinstalled without retrying old system kernels.
