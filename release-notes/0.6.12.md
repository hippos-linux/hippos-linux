### New systems

- **Linux Games**: native games installed with Discover, apt or the Content Downloader appear here with a description and screenshot. Games you already have move here from Ports when you update; Ports keeps the built-in game cores.
- **Web Apps**: Netflix, YouTube, Disney+, Prime Video, Twitch, Spotify and more open full screen with their own sign-in. Add them from the Content Downloader, or add any website with "Add a web app". Streaming sites play protected video.
- **Desktop Shortcuts**: shortcuts you put on the desktop show up in EmulationStation.
- **Windows 98**: runs in DOSBox Pure, keeping each game's Windows changes separate. DOSBox-X is available as an alternative emulator.

### Apps and stores

- Discover is in Desktop Shortcuts, so you can install apps and games from Debian and Flathub without leaving EmulationStation. Snap is blocked.
- Apps installed from a store now show up in Flatpak as soon as the install finishes.
- Apt games in the Content Downloader have screenshots.

### Controls

- Controller as mouse: the left stick moves the pointer, A or R2 clicks, and the right stick scrolls. It's on by default for apps (Flatpak, Web Apps, Desktop Shortcuts), and can be turned on for Linux Games, Ports, Windows, Lutris, Heroic, DOS and Windows 98 games. Pointer speed is a slider.
- An on-screen keyboard appears when a text box is selected, with L2 for Shift and R2 for accents. A keyboard hotkey shows or hides it. It's on by default for apps and can be turned on for any game.
- Light guns are merged into one gun per player: AimTrak, GunCon 2, GunCon 3 and Retro Shooter (with calibration: hold Select for 3 seconds), GUN4IR, OpenFIRE, Blamcon, Fusion, XGunner and OneHit. Sinden guns work on PC and their software is set up for you.
- Racing wheels report their rotation, with force feedback for Logitech and Thrustmaster wheels.

### Games and emulators

- MAME starts reliably again and its controls are mapped correctly.
- Emulator options you set in EmulationStation (for a system, a folder or a game) now actually reach the emulator. Many were being ignored.
- Switch emulators use the keys and firmware in `bios/switch`.
- Laserdisc plays `.ogv` games in DirkSimple.
- ROM folders named the way other front-ends name them join the right system.
- Unused RetroArch cores are removed, making the system smaller.

### Raspberry Pi

- Updates boot into the new version. Before, a Pi could fail to boot after updating.
- Chromium plays protected video, and Chromium shortcuts open in kiosk mode.

### System

- Plugging in a USB sound device switches to it, and unplugging switches back.
- USB drives plugged in after boot are mounted and usable.
- Chromium no longer asks for a keyring password.
- Game lists refresh after you close a menu, not while it's open.
- New themes logos for Linux Games, Lutris, Flatpak and Mr. Boom.
