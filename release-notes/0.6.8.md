version: "0.6.8"
summary: "An optional login screen, a new boot menu, faster and more reliable switching between EmulationStation and the desktop, Waydroid working again, and game drives that ask before joining your library."
---

### Login and sessions

- HippOS can now start at a login screen. It's off by default: turn off Auto Login in EmulationStation under System Settings → Security, after setting a root password there. The login screen uses that password.
- The login screen works with a controller, a keyboard or a mouse. Choose whether to start in EmulationStation or the desktop from the Start In list; your choice is remembered for the next start. Power off and Restart are under the Power button.
- EmulationStation's Quit menu has a new Log Out option, next to Switch to Desktop.
- EmulationStation and the desktop now run in a single login, so switching between them is quicker and no longer restarts the whole session.
- Things that need the person in front of the machine to be recognised now work: password prompts on the desktop appear, drives mount from the desktop's file manager, and Airplane mode turns Bluetooth off as well as Wi-Fi.
- Leaving a desktop now closes everything it started. GNOME in particular used to leave apps running behind EmulationStation.

### Boot and shutdown

- The boot menu has a new HippOS look, matching EmulationStation.
- Fixed error messages and a "Press any key to continue" pause at every start. This also fixes the automatic fallback to the previous version after an update fails to boot three times, which never worked.
- Shutting down and restarting show the HippOS screen again, without a failure message.

### Game drives

- A drive with games on it no longer joins your library automatically. EmulationStation asks first, including for drives already plugged in when HippOS starts, and remembers your answer. If you used a drive with an earlier version, you'll be asked about it once.
- Ejecting a drive from EmulationStation works. Before, the drive stayed mounted.
- Formatting a drive from EmulationStation works.
- Fixed your game library going empty after merging, ejecting or plugging in a drive, or adding a network share.

### Controllers

- If you use a DualSense or DualShock controller, map it again once in EmulationStation (Controller & Bluetooth Settings). Its buttons now match between EmulationStation and your games; before, Start could end up on L2 in RetroArch.
- Steam Controller (2026) works as a controller straight away, without holding Start first.
- On handhelds such as the AYANEO 2021, the built-in controller no longer keeps disconnecting and reconnecting.

### Games and apps

- Waydroid (Android apps) starts again, and Hotkey+Start closes it.
- Lutris opens LutrisView, a library browser in EmulationStation's style that works with a controller.
- Hotkey+Start now closes games and apps that ignored it before, such as ones showing an error or a first-run screen.
- Hotkey+Start returns from Steam to EmulationStation straight away, instead of after half a minute.
- Many emulators start correctly again, including Vita3K, shadPS4 and PPSSPP. Ryujinx no longer asks about memory settings at every start, and Windows games no longer stop at a .NET install prompt.
- Games stored as .squashfs files start again.
- The App Store can install and remove apps again.
- EmulationStation no longer stays hidden behind a black screen after another window closes.
- Emulator updates now include builds that need this version of HippOS, starting with DuckStation.

### Other fixes

- Intel Wi-Fi cards such as the AX200 keep working after sleep.
- Pressing a controller button twice by accident no longer loses a setting.
- If you never chose a language, it is now set to English (UK).
