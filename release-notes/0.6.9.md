version: "0.6.9"
summary: "Fixes HippOS not starting after updating to 0.6.8, and makes updates work when another system's boot menu starts HippOS."
---

### Updating

- Fixed HippOS stopping at a text console after updating to 0.6.8, with no sound and Flatpak apps not opening. If you are on 0.6.8 and stuck there, log in at the console and run `sudo hippos-upgrade` to install this update, then restart.
- If another system's boot menu starts HippOS (for example a dual-boot set up by hand), updates now take effect. Point that boot menu at `/@rootfs/boot/vmlinuz` and `/@rootfs/boot/initrd.img` with `rootflags=subvol=@rootfs` once; the newest version is always installed there, and earlier versions are kept as `@rootfs-<version>` for rollback.

### Controllers and keyboards

- Pressing Backspace on a keyboard no longer switches to the desktop. Pressing Backspace and Space together exits a game without also switching to the desktop.

### Games and apps

- Waydroid's network works on the LTS kernel too.
