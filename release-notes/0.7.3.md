### Quick menu

- The quick menu (Hotkey + A) is now drawn by EmulationStation itself instead of being a separate app. It opens a lot faster, about a second on an R36S where it used to take up to five.
- It keeps the same look and tabs: game details and artwork, keys, system, outputs and recording, with the game showing faintly behind it.
- Picking a key for a button on the Keys tab now uses a proper on-screen keyboard. X adds keys to a combination, Y sets it to not mapped.
- Buttons that can't be undone, like resetting your keys, ask you to press again to confirm.
- It closes by itself after 20 seconds of no input.

### RomM

- RomM is built into EmulationStation now. Pair it with your RomM server under System settings, then browse and download games and keep your saves in sync.
- PS3 PSN games and disc game updates and DLC downloaded from RomM are installed into RPCS3 for you.
- Switch updates and DLC go in `roms/switch_update` and Eden, Citron and Ryujinx pick them up.

### Games and controllers

- Games start quicker, especially on handhelds: the launcher only loads what the game needs, and games run at a higher priority than background stuff.
- Riverhorse (PS1) is updated to 1.4.0.
- Trackballs and spinners: declare yours under Controller settings, Trackballs and spinners, by moving it when asked. Games that use one get it as the mouse.
- Folders in your ROM folders show up as folders in EmulationStation by default.
- Scraping without a ScreenScraper account works again.
- Port games show up with their full details as soon as you add their data, and the data files themselves no longer show up as games.
- New theme art for Switch 2, Sega Channel, IGS PC, itch.io, Namco System 357/369, the RGS systems, Voxatron, the wheel, light gun, spinner, trackball and vertical arcade collections, and every system gets its own world now.

### Settings

- Wi-Fi remembers every network you connect to instead of only the last one.
- CPU security mitigations can be turned off under System settings, Security, for a bit more speed on some machines. It takes effect after a reboot.
- Handhelds with RGB LEDs get colour, brightness and a battery level mode. The GameForce Chi's button and power LEDs are kept between boots.
- The video output menu switches screens properly.

### Storage

- The duplicates check in Smart storage now finds the same game even when it's zipped differently or not zipped at all. It stopped listing files inside ports and empty launcher files as duplicates. The first scan after updating takes a while because every game gets checked again, later ones are quick.

### Fixes

- Pressing Back on the "new drive detected" or "network share detected" prompts used to pick the last button, which is merge (or format and merge). Back now means no.
- The system carousel showed RANDOM on both X and Y when All games was turned off. Y now does nothing then.
- The Collections entry is spelt with a capital C.
- Brightness hotkeys step from the level your screen is at, and never go fully dark.
- Machines without an NVIDIA driver no longer show an NVIDIA error as the GPU temperature.
