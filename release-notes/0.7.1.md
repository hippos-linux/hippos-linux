### RK3326 handhelds (R36S)

- The desktop now works on handhelds. I've been using LXQt on my R36S and it runs fine, so it's in the image now. The on-screen keyboard is bigger, comes up in the terminal, and the d-pad stays on the keyboard while it's open instead of moving things behind it.
- Thermals are redone, so the 1008 MHz cap is gone. The CPU goes up to 1296 MHz and the GPU up to 520 MHz, and both slow down together to hold the chip around 85 °C. Before, only the CPU could be slowed, and with just two speeds it would jump straight to the top and overheat. I left mine scraping overnight on charge for five hours and it peaked at 89 °C with no shutdowns, then went straight back to full speed when it finished.
- Games run in high performance mode and go back to normal when you exit. You can still set a CPU limit in the quick menu if you want it cooler or want to save battery.
- The memory clock now speeds up and slows down with load instead of sitting at full speed all the time.
- The volume at boot is what the menu says it is. It used to show 0% and play at full volume after a reboot.
- On the desktop, apps open maximized so they don't end up behind the taskbar on the small screen.
- A second SD card (like EASYROMS) gets merged in even when it's slow to mount, and the merged drive markers show for every drive.

### HippOS Store

- The desktop has a new HippOS Store app instead of Discover. It's laid out the same way, with categories, app pages, Installed and Updates, and it puts HippOS picks, Flathub and Debian in one place. If an app is on more than one, you pick where to install it from.
- It's light enough for handhelds and works with a controller: the d-pad moves around, Start opens or installs, Select goes back. Apps you install here and in the EmulationStation store are the same list.
- There's a Recomps section with nearly 1,000 fan-made PC ports and recompilations (Zelda 64: Recompiled, Ship of Harkinian, Sonic 3 A.I.R. and loads more), from RecompLauncher's catalogue. They install straight from each project's GitHub and show up in Linux Games, no extra launcher needed. You still need your own copy of each game.
- The store's Updates page covers HippOS too: the system, EmulationStation and emulator updates sit above your app updates, and Update everything does the lot in one go, then offers a restart if one's needed. That replaces the old HippOS Update app, and Discover's gone from PC images now the store does its job, which frees up a fair bit of RAM. Apt updates there only touch packages you installed yourself, since everything else comes with HippOS updates.
- You can sort by most installed (from Flathub's and Debian's own install numbers), top rated, name or recently updated, see star ratings and reviews, and hide Flathub or Debian if you only want one of them. It's dark by default with a light mode button.

### PortMaster

- PortMaster comes installed and ready in Ports.
- Unity ports that crashed when loading their game files from the ROM card now start.
- 32-bit ports have sound.
- A port that crashes on exit doesn't leave its game running behind the menu anymore.

### Drives and storage

- Drives you plug in or that mount late join your merged drive without a remount, and leave it again when you take them out.
- Games stored on a merged drive or a network share have a marker in the game list.
- More alternative folder names are picked up when you merge a drive, like famicom, sfc, genesis, segacd, turbografx and wonderswan.
- The storage scan only runs when you hit Scan now in the storage menu. It used to run in the background and on a big card it could go for over an hour without finishing. It's a lot quicker now too, and carries on where it stopped.
- Saves, ROMs and scraped art can be written when a card has less than 4 GB free. Before, a card under 4 GB free refused new files even with plenty of space left.
- Updates check there's enough room on the drive before downloading, so they stop with a clear message instead of failing halfway.

### Fixes

- Updates on handhelds no longer get rolled back on the next reboot. The update could boot fine but wasn't marked as good in time, so the reboot after went back to the old version.
- Network shares found in the desktop's file manager open now. Some NAS boxes and Windows PCs only share over IPv4, and the file manager was trying to reach them over IPv6.
- The shell prompt no longer flashes up between the boot splash and the menu.
- The menu uses less CPU when you're not doing anything, which helps battery life on handhelds.
- Demul works. Before, it asked you to download it yourself and never actually ran.
- Content packs that add their own Windows systems can launch their games.
- The Discover icon on the desktop is gone where Discover isn't installed, and installing a desktop from the switcher doesn't get stuck on a config file question anymore.
- Riverhorse is updated to 1.1.0.
- RetroArch and a few other emulators no longer show an update every day when nothing in them has changed.
- Desktop apps like maps and weather can find your rough location now, from nearby Wi-Fi or your connection. There's no GPS on these devices, so it's only roughly where you are.
- Proton is updated to GE-Proton11-14. It includes the video fixes Windows Arcade Loader uses for movies in games like Pokkén Tournament, Wasteland Racers 2071 and Big Foot Crush. I haven't been able to test those games myself, so let me know how they go.

### Docs

- The wiki has moved to [hippos-linux.org/docs](https://hippos-linux.org/docs/), with install guides, device pages and a page for every system with its emulators, file types and BIOS files. Old wiki links take you to the right page.
