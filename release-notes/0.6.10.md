### Games and emulators

- PS2 games start with any PS2 BIOS file, whether it's in `bios/ps2` or straight in `bios/`, and the missing-BIOS warning only shows when there really is none. Before, a BIOS anywhere but `bios/ps2` left the game on a hidden error and returned to EmulationStation with "UNKNOWN ERROR: 250".
- Namco System 246/256 games run on pcsx2x6. Put the `.acgame` sets in `roms/namco2x6` and the BIOS files in `bios/namco2x6`.
- Chihiro games run on a dedicated Chihiro build of xemu.
- Lindbergh games run on the new Lindbergh loader.
- Sega Model 2 games run natively by default, without Wine. The Wine emulator is still available per game.
- NanoBoyAdvance is available as a Game Boy Advance emulator.
- Games open on the monitor chosen in EmulationStation.
- Alt+F4 closes the game or app in front, and the exit hotkey closes games straight away instead of after a few seconds.

### ROMs

- SMB and NFS shares on your network can be found and added to your ROM library, including shares that need a username and password.

### Controllers

- Xbox Series X|S and Xbox One controllers stay connected over Bluetooth, and the Xbox button works as the Hotkey.

### System

- Restart and Shut Down in EmulationStation's menu now restart or shut down the machine instead of only restarting EmulationStation.
- Installing KDE Plasma or GNOME with apt works, and HippOS still starts normally afterwards.
