### Handhelds

- The kernel's handheld drivers are back. They had been missing from the last few releases, so several built-in controllers, fans and buttons didn't work fully.
- **ROG Xbox Ally and ROG Ally**: the built-in controller works through InputPlumber with every button, including X, RB, L3 and R3. If you added a manual button remap file to work around this, delete it and map the controller again in EmulationStation.
- **ROG Xbox Ally speakers** work without copying any firmware by hand.
- The kernel scheduler and low-memory tuning that keep games smooth under load are back on both the standard and LTS kernels.

### Windows and PC games

- **Windows Arcade Loader** launches Windows-based arcade games from EmulationStation, using the bundled GE-Proton.
- Windows games start through the umu runner, and `.pc` and `.wine` games honour a `DIR=` line in their launch file.

### New in the Content Downloader

- Flatpak games open from Linux Games, and downloadable games install into their own folder with a Linux Games launcher.
- AppImages can be installed as Linux Games or Linux Apps, or dropped into the new AppImage folder.
- Sunshine opens from Linux Apps: it starts streaming, stays on after a restart and shows its pairing page.

### Systems and emulators

- Java ME games play out of the box with FreeJ2ME-Plus, Java included, on PC and Raspberry Pi.
- DOS games use DOSBox Pure by default; folder games start their `dosbox.bat` in either DOSBox.
- PICO-8 games fall back to the retro8 core when the official PICO-8 isn't installed.
- Amstrad CPC uses Caprice32, Apple II uses AppleWin, ColecoVision uses Gearcoleco, Enterprise uses ep128emu, Sega Pico uses PicoDrive and Cassette Vision uses its own core.
- Saturn uses YabaSanshiro on Raspberry Pi, and Supermodel and Keisho (formerly sm2-emu) now run on Raspberry Pi too.
- 19 more arcade PC systems.
- Wii games get a Wii Remote configuration in Dolphin.
- 28 more controllers work without mapping, and the Steam Controller 2 works in EmulationStation straight away.

### Faster boot and launch

- Boot no longer waits for Wi-Fi to connect, for NVIDIA cards to initialise, or for large ROM libraries to be scanned.
- Games start sooner: the launcher's setup runs in parallel and its code is precompiled.
- When a game can't start, EmulationStation tells you why, for example which emulator isn't installed.

### Network shares and updates

- Network shares are only offered when they contain games, and the prompt shows how many ROM, BIOS and save files were found.
- After an update, you're told when changed system files were backed up, with an option to restore them.
- The dev update channel falls back to stable updates when there's no newer dev build.

### Fixes

- Games on rotated portrait screens keep the screen's own resolution.
- The main menu shows the chosen media center straight away.
- Log bundles include controller mappings, to help with controller reports.
