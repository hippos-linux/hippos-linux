---

### New theme

- HippOS has a new default theme, in which every system is its own generated planet. The carousel fades between worlds as you scroll.
- Updating switches you to it if you were on the previous default. If you chose a different theme, you keep it. The previous theme is still included, under Theme Set in EmulationStation's settings.

### New apps and launchers

- Quiver Launcher is now available on PCs. HippOS installs it for you in the background, and each app you install in Quiver gets its own entry in EmulationStation, with its details and artwork.
- Lutris games launch from EmulationStation. They were listed before, but failed to start.
- Lutris itself now has an entry in EmulationStation, and your Lutris games show the cover art and banners Lutris has for them.
- Lutris is now the latest version from the Lutris project, 0.5.22, so the "no longer supported" banner is gone.
- Hotkey+Start closes Lutris and its games and takes you back to EmulationStation.
- Hotkey+Start also closes Heroic Games Launcher.
- Flatpak apps fill in their own name, description and icon. Anything you've scraped or edited yourself is kept.
- Flatpak apps installed for your user now appear in EmulationStation. Before, the Flatpak system could stay empty.

### Fullscreen

- Apps and games started from EmulationStation now open fullscreen, with no title bar. The same apps stay in normal windows on the desktop.

### EmulationStation

- The music popup shows the song title and artist for OGG and FLAC files as well as MP3, instead of the file name.
- Built-in collections now have capitalised names, such as All Games, Favourites and Last Played. Custom collections keep the names you gave them.
- Navigation sounds now work in the default theme, and are turned on by default.
- Fixed menu panels and button boxes appearing in the wrong place.
- If EmulationStation crashes, it now restarts. Before, you were left with a black screen.
- Fixed game details not saving because the game list file was owned by the wrong user.
- The ScreenScraper login is now supplied when HippOS is built. Scraping works as before.

### Fixes

- Hotkey+Start no longer sometimes switches to a text console (tty4) when closing a game.
- Updating RetroArch no longer deletes all of its cores, which made games fail with "Core not found".

### Diagnostics

- Uploaded logs no longer include Wi-Fi passwords and similar settings in plain text.
- Uploaded logs now include launch output, so failed game launches are easier to diagnose.
